# Church Technology Policy and Administration

## Primary reference

Church Meetinghouse Technology:

<https://tech.churchofjesuschrist.org/wiki/Meetinghouse_Technology>

This project is a local planning and documentation tool. It does not
replace Church policy, FMG processes, or required authorization.

## Ownership

Distinguish FMG-owned equipment from locally managed equipment.

If ownership is unknown, record it as unknown until verified.

## Authorization

Physical access to equipment does not automatically authorize
configuration changes.

Do not independently change network infrastructure, routers,
DHCP, DNS, VLANs, or other managed network services without
the required authorization.

## FMG equipment

Use the appropriate FMG process for FMG-owned equipment.

Do not assume local funds can be used to purchase or replace
FMG-owned equipment.

## Information protection

Do not store:

- Passwords.
- Private keys.
- Confidential Church or member information.
- Sensitive network configuration details.
- Personal information that is not necessary for technology support.

## Project scope

Clerk computers are excluded from this project's inventory and
management scope.
